# FAQ do gerente

## O que o gerente pode consultar?

O gerente pode consultar sugestões encaminhadas para decisão e informações e
métricas das lojas que estejam dentro do seu escopo autorizado.

## O gerente pode editar uma sugestão encaminhada?

Sim. Antes de decidir, o gerente pode ajustar a quantidade de lotes de uma
sugestão de pedido ou o percentual de desconto de uma sugestão de promoção. O
valor original do modelo, o valor encaminhado pelo funcionário e o valor final
do gerente permanecem distinguíveis no histórico, quando aplicável.

## Como o gerente decide uma sugestão?

O gerente pode aprovar ou recusar uma sugestão encaminhada. A recusa exige uma
justificativa. A decisão fica registrada no QuiStock e não envia um pedido nem
ativa uma promoção fora do aplicativo.

## O gerente pode criar uma sugestão manual?

Sim. O gerente pode criar uma sugestão manual de pedido ou promoção para sua
loja. Ela é identificada com origem `GERENTE` e já nasce aprovada, sem depender
de outra decisão.

## O que a aprovação representa?

A aprovação registra a decisão dentro do QuiStock. Operações externas, como
enviar um pedido de compra ou ativar uma promoção, não são executadas pelo
aplicativo.
