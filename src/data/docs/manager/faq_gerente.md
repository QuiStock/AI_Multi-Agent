# FAQ do gerente

## O que o gerente pode consultar?

O gerente consulta sugestões encaminhadas para decisão e informações das lojas
que estão no seu escopo autorizado. O acesso é derivado da identidade
autenticada e não de dados enviados livremente na mensagem.

## O gerente pode editar uma sugestão encaminhada?

Sim. Antes de decidir, o gerente pode editar a quantidade de lotes de uma
sugestão de pedido ou o percentual de desconto de uma sugestão de promoção. O
valor encaminhado pelo funcionário e o valor final decidido permanecem
distinguíveis e auditáveis.

## Como o gerente decide uma sugestão?

O gerente pode aprovar ou recusar uma sugestão encaminhada. Uma recusa exige
justificativa. A decisão não dispara pedido de compra nem ativa promoção.

## O gerente pode criar uma sugestão manual?

Sim. Uma sugestão manual criada pelo gerente para sua loja registra origem
`GERENTE` e nasce aprovada, sem depender de outra decisão.

## O que a aprovação representa?

A aprovação representa uma decisão registrada dentro do Quistock. Operações
externas, como enviar um pedido ou ativar uma promoção, estão fora do limite
funcional do aplicativo.
